# Docker Image Deployment Using Docker Hub

## 1. Create Docker Network

```bash
docker network create mynetwork
```

## 2. Create Persistent Database Volume

```bash
docker volume create pgdata
```

## 3. Set Docker Image Version

Replace the example commit ID with the actual Git commit ID generated by GitHub Actions.

```bash
IMAGE_TAG=dev-a82f91c7d123456789abcdef123456789abcdef12
```

## 4. Pull Docker Images from Docker Hub

### Pull Backend Image

```bash
docker pull gauravhalnawar123/my-webapp-backend:$IMAGE_TAG
```

### Pull Frontend Image

```bash
docker pull gauravhalnawar123/my-webapp-frontend:$IMAGE_TAG
```

### Pull Database Image

```bash
docker pull gauravhalnawar123/my-webapp-database:$IMAGE_TAG
```

Verify downloaded images:

```bash
docker images
```

## 5. Run PostgreSQL Container

```bash
docker run -d \
  --name my_postgres \
  --network mynetwork \
  --restart unless-stopped \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=12345 \
  -e POSTGRES_DB=mydatabase \
  -v pgdata:/var/lib/postgresql/data \
  gauravhalnawar123/my-webapp-database:$IMAGE_TAG
```

Check PostgreSQL logs:

```bash
docker logs my_postgres
```

Wait until PostgreSQL is ready:

```bash
until docker exec my_postgres pg_isready -U admin -d mydatabase; do
  sleep 2
done
```

## 6. Run Backend Container

```bash
docker run -d \
  --name my-python-container \
  --network mynetwork \
  --restart unless-stopped \
  -e DB_HOST=my_postgres \
  -e DB_PORT=5432 \
  -e DB_NAME=mydatabase \
  -e DB_USERNAME=admin \
  -e DB_PASSWORD=12345 \
  -e DB_SSLMODE=disable \
  -e CORS_ORIGINS="*" \
  -p 5000:5000 \
  gauravhalnawar123/my-webapp-backend:$IMAGE_TAG
```

Check backend logs:

```bash
docker logs my-python-container
```

Test backend API:

```bash
curl http://localhost:5000/ready

curl http://localhost:5000/students

curl http://localhost:5000/items
```

## 7. Run Frontend Container

For Killercoda:

```bash
docker run -d \
  --name my-frontend-container \
  --network mynetwork \
  --restart unless-stopped \
  -e API_URL="https://5229138bd58d33e0-1-5000.papa.r.killercoda.com" \
  -p 3000:80 \
  gauravhalnawar123/my-webapp-frontend:$IMAGE_TAG
```

For AWS EC2:

Replace the API URL with your EC2 public IP:

```bash
docker run -d \
  --name my-frontend-container \
  --network mynetwork \
  --restart unless-stopped \
  -e API_URL="http://YOUR_EC2_PUBLIC_IP:5000" \
  -p 3000:80 \
  gauravhalnawar123/my-webapp-frontend:$IMAGE_TAG
```

## 8. Verify Running Containers

```bash
docker ps
```

Expected containers:

| Container | Image | Port |
|---|---|---|
| my_postgres | my-webapp-database | 5432 (internal) |
| my-python-container | my-webapp-backend | 5000 |
| my-frontend-container | my-webapp-frontend | 3000 |

## 9. Access the Application

Open the frontend:

```text
http://YOUR_EC2_PUBLIC_IP:3000
```

For Killercoda, open the generated port 3000 URL.

## 10. Verify Frontend Runtime Configuration

```bash
docker exec my-frontend-container \
  cat /usr/share/nginx/html/config.js
```

Expected configuration:

```javascript
window.APP_CONFIG = {
    API_URL: "YOUR_BACKEND_PUBLIC_URL"
};
```

## 11. Useful Docker Commands

### View Containers

```bash
docker ps

docker ps -a
```

### View Images

```bash
docker images
```

### View Logs

```bash
docker logs my_postgres

docker logs my-python-container

docker logs my-frontend-container
```

### Follow Backend Logs

```bash
docker logs -f my-python-container
```

### Access PostgreSQL

```bash
docker exec -it my_postgres psql -U admin -d mydatabase
```

### Inspect Docker Network

```bash
docker network inspect mynetwork
```

### Stop Containers

```bash
docker stop my-frontend-container

docker stop my-python-container

docker stop my_postgres
```

### Remove Containers

```bash
docker rm -f my-frontend-container

docker rm -f my-python-container

docker rm -f my_postgres
```

### Remove Unused Images

```bash
docker image prune -a
```

**Warning:** Do not remove the `pgdata` volume if you want to preserve your database records.

## Deployment Flow

```text
GitHub
   |
   v
GitHub Actions
   |
   v
Build Docker Images
   |
   v
Push Images to Docker Hub
   |
   v
Pull Images on AWS EC2 / Killercoda
   |
   v
Create Docker Network
   |
   v
Run PostgreSQL Container
   |
   v
Run Backend Container
   |
   v
Run Frontend Container
   |
   v
Access Application
```

**Key Learning:** Build once, publish versioned images, pull them onto another VM, and run containers using runtime environment variables. No application source code or Dockerfiles are required on the deployment VM.
